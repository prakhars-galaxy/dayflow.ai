AI & privacy

This standalone demo uses a local, rule-based recommendation engine. Your tasks and preferences stay in this browser's local storage. No data is sent to an AI service. A real generative-AI integration requires a secure backend and an AI provider API key; never put a secret API key directly in front-end code.
