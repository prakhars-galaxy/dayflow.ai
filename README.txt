DAYFLOW AI — MOBILE APP / PWA

CONTENTS
- index.html: the complete mobile-friendly app
- manifest.webmanifest: installable app metadata
- service-worker.js: offline app shell cache
- icon.svg: app icon

QUICK PREVIEW
Open index.html in a desktop or mobile browser. All core features work locally.

INSTALL AS AN APP
For the full installable PWA experience, host this folder on an HTTPS website
(or localhost during development). Then:
- Android: open the site in Chrome and choose Install app / Add to Home screen.
- iPhone: open the site in Safari, tap Share, then Add to Home Screen.

FEATURES
- Dashboard, day planner, tasks and priorities
- Time-use insights
- Focus timer and interruption checklist
- Well-being planning
- AI-style schedule gap suggestions using a local rule-based engine
- Browser local storage for tasks and preferences

AI NOTE
This demo's recommendations are generated locally with rules; it is not connected
to a generative AI service. A production AI integration requires a secure backend.
Do not place private API keys in browser code.
